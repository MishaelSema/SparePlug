### SparePlug - Multi-Vendor Auto Parts Marketplace
**Stack:** PHP (MVC), MySQL, Tailwind CSS, JavaScript, Twilio/WhatsApp API  
**Repository:** [github.com/MishaelSema/SparePlug](https://github.com/MishaelSema/SparePlug) | **Live:** [Insert Live Link Here]

*   **Platform Development:** Engineered a full-stack e-commerce platform bridging auto part vendors and vehicle owners in Cameroon, featuring role-based access control (Admin, Vendor, Buyer).
*   **Vendor Ecosystem:** Built a comprehensive vendor dashboard enabling real-time inventory management, inquiry tracking, and subscription handling (Free/Premium tiers).
*   **Search & Discovery:** Implemented efficient SQL search queries with filtering by Vehicle Make/Model/Year, significantly reducing part discovery time.
*   **Lead Generation:** Integrated direct "Chat on WhatsApp" functionality with backend tracking to record and analyze lead sources for vendors.
*   **Performance:** Optimized database schema and image loading for low-bandwidth environments, ensuring sub-2s load times.
